Recuperar fotos e documentos sem restaurar o banco

Ideal para a reinstalação no mesmo PC: recupera apenas uploads e XMLs do backup completo local. O PostgreSQL existente não será modificado e nenhum anexo atual será sobrescrito.

Clique em Escolher arquivo para abrir a janela de pastas do computador.

Selecione o ZIP completo (não arquivos .part). Desligue o GFARM antes de importar. O banco PostgreSQL permanecerá intocado.

Restaurar em banco vazio

Proteção obrigatória: a restauração é recusada se o banco contiver tabelas ou se os diretórios de fotos e XMLs contiverem arquivos. O Control nunca sobrescreve um banco em produção.

Gerenciamento remoto seguro

O Control escuta apenas no próprio computador por padrão. Para acesso externo, instale o Tailscale no servidor e no dispositivo administrador e habilite o IP privado da rede Tailscale abaixo.

Configure permissões ACL/grants no Tailscale. Não encaminhe a porta 8787 diretamente no roteador ou em um túnel público.

Autorização de leitura do GitHub privado

O serviço utiliza uma chave SSH própria. Adicione a chave pública em GitHub → Repositório GFARM → Settings → Deploy keys, SEM permitir escrita.

Não compartilhe a chave privada. Apenas a chave pública deve ser copiada para o GitHub.

Diagnóstico do GFARM

Verifique status, instalação, operações e erros. O Control não remove dados nem executa reparos destrutivos automaticamente.
